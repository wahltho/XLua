Full Description

Optimized XLua is my independent community fork of Laminar Research's open-source XLua plugin. It is not an official Zibo Mod product and is not part of an official Zibo or LevelUp aircraft release. It can be installed as an optional runtime in supported aircraft installations.

This fork aims to reduce overhead in XLua's script discovery, reload checks, command and dataref lookups, logging and per-frame callbacks. The effect depends on the aircraft and workload; no particular frame-rate gain is guaranteed. If your plugin menu shows a JIT: On / JIT: Off control, that control comes from this fork, not from the stock Zibo package.

Stable and Beta

The Stable channel follows the optimized XLua 1 line. Users running X-Plane 12.4.3 must select Stable; the current Stable release is XLua 1.3.7r5.

The XLua 2 Beta requires X-Plane 12.4.4 or newer. It uses SDK functions introduced with X-Plane 12.4.4 and does not load on X-Plane 12.4.3. The Beta channel is a prerelease for testing even on a compatible simulator version. Read the validation notes and installation instructions for the specific release before choosing Beta; a successful build is not proof of simulator behavior. Current packages and release notes are on the Optimized XLua GitHub releases page.

Installing or updating

Close X-Plane before changing the plugin. For supported Zibo and LevelUp aircraft, the independent X-Plane 737NG Maintenance Toolkit offers Optimized XLua under Components & Tools. Select the aircraft installation and the Stable or Beta channel, check the release, then review and confirm the proposed action. The Toolkit validates recognized runtime files, creates a backup and preserves the aircraft-owned plugins/xlua/scripts directory. Use a current Toolkit release for Beta packages. Selecting Beta in the Toolkit does not make XLua 2 compatible with X-Plane 12.4.3.

Manual installation remains available from the matching GitHub release. Follow that release's instructions: back up the complete aircraft plugins/xlua folder, replace only the supplied runtime files inside that existing folder, and leave plugins/xlua/scripts unchanged. Do not create a second plugins/xlua2 folder or leave old and new runtime binaries side by side. Earlier experimental XLua 2 packages may require the cleanup described in the current release notes.

Support and feedback

Please use the comments on this download page for Optimized XLua questions, not the official Zibo Discord or forum. Zibo and Skymatix do not support this independent runtime. When reporting a problem, include the XLua release, operating system, aircraft version, X-Plane version and relevant Log.txt entries. Questions about the Toolkit itself belong on its own download page.

If XLua 2 is installed on X-Plane 12.4.3, Windows may report Error Code = 127 : The specified procedure could not be found. XLua then never starts, so subsequent missing-dataref errors from FMOD, AFCBridge, BFC_Throttle or other integrations are expected follow-on symptoms. Restore the Stable XLua 1 runtime before investigating those secondary messages.

Optimized XLua is provided without warranty. Keep a backup of your aircraft before changing its plugins.
